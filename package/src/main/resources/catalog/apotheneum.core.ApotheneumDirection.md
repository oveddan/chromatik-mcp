## Summary

Rotates the entire rendered image around Apotheneum in 90-degree increments, remapping each cube face and each cylinder quadrant to the next one over.

- Rotates all four cube faces (front/right/back/left) together, independently for exterior and interior.
- Rotates the cylinder in the same four quadrant steps, matching the cube's four-way symmetry.
- No rotation is applied when the step count is 0, or when the effect's enabled amount is at or below zero — in both cases the frame passes through unmodified.

## Parameter interactions

- The step count is SAMPLED fresh each frame (an integer 0-3, wrapping), so live changes take effect on the next frame as a hard quadrant snap rather than a smooth rotation — there is no interpolation between steps.
- The effect's enabled amount is checked only as an on/off gate (zero or below skips entirely); intermediate enabled/mix values do not blend a partial rotation.

## Usage tips

- Use this to cheaply re-orient content generated by an upstream pattern (e.g. make a "front-facing" pattern appear on a different face) without changing the pattern itself.
- Because rotation is quadrant-snapped rather than continuous, do not expect a smooth spin effect from sweeping the step parameter with a modulator — pair it with a separate crossfade if a smooth transition between orientations is needed.
