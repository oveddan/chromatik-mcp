## Talk to your lighting rig

Connect Claude Code, Claude Desktop, Cursor, or any MCP client to a running
[Chromatik](https://chromatik.co/) instance and compose a show in natural language:
build channels and pattern playlists, chain effects, wire LFOs and macro knobs,
manage the color palette, capture snapshots — all live, all undoable with Cmd-Z.

```sh
curl -L --create-dirs -o ~/Chromatik/Packages/lx-mcp.jar \
  https://github.com/oveddan/lx-mcp/releases/download/latest/lx-mcp.jar
# enable LX-MCP in Chromatik Preferences → Plugins, restart, then:
claude mcp add --transport http lx "http://127.0.0.1:$(jq -r .port ~/.lx-mcp/status.json)/mcp"
```

## Part of a bigger pattern

lx-mcp does for LX/Chromatik what
[TouchDesigner MCP](https://github.com/8beeeaaat/touchdesigner-mcp) does for
TouchDesigner: embed the agent interface inside the creative tool's runtime, so
AI collaborators manipulate live state instead of editing project files. Agentic
workflows for artists, not just programmers.
